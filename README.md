# DevX — ایجنت خودمختار DeepSeek × GitHub

ایجنت پایتون حرفه‌ای **نسخهٔ ۴** که با **اکانت chat.deepseek.com** (Playwright) گفت‌وگو می‌کند و با **GitHub Classic Token** روی حساب گیت‌هاب شما عملیات گسترده انجام می‌دهد — **۵۷ ابزار پلاگین‌پذیر**، حافظهٔ برداری RAG با سنجاق/فراموشی و ماشین‌زمان، زیرایجنت و بازتاب، دروازهٔ تایید انسانی + ممیزی زنجیرهٔ هش + سندباکس، زمان‌بند و نگهبان مخزن و اعلان‌ها، چندسشن موازی، بازار مهارت، persona هر پروژه، خط زمانی و پالت ⌘K — همهٔ این‌ها در **رابط وب HUD به نام DevX** با تم قرمز-مشکی و اکسنت‌های فیروزه‌ای/زرد.

## چه چیزهایی دارد که ایجنت‌های معمولی ندارند؟

| قابلیت | توضیح |
|---|---|
| 📁 **مدیریت پروژه‌ها** | هر چت جدید یک پروژه است: **نام را خودت انتخاب می‌کنی، آیدی به‌صورت خودکار در پس‌زمینه ثبت می‌شود** («پروژه ۱ — تست»). با حذف هر پروژه، آیدی‌های بعدی **خودکار بازچینش می‌شوند** تا همیشه فشرده بمانند (۱،۲،۳،…) — داده‌ها با «کلید پایدار» داخلی نگه داشته می‌شوند پس هیچ‌چیز جابه‌جا یا گم نمی‌شود |
| 🧠 **حافظهٔ ماندگار** | حقایق کاربر/پروژه، درس‌های خطا، یادداشت‌ها و تاریخچهٔ تسک‌ها ذخیره می‌شود؛ ابتدای هر تسک، حافظهٔ مرتبط (جستجوی کلیدواژه‌ای تطبیق‌پذیر با فارسی) به پرامپت تزریق می‌شود — **همه چیز را یادش می‌ماند** |
| 🔐 **ایزولاسیون کامل پروژه‌ها** | هر پروژه حافظه و مهارت‌های **کاملاً جداگانه** دارد (`memory/projects/<key>/` و `skills_learned/projects/<key>/`)؛ اطلاعات هیچ دو پروژه‌ای قاطی نمی‌شود و سوییچ پروژه یعنی سوییچ کامل حافظه/مهارت/رجیستری |
| 🔎 **حافظهٔ برداری (RAG)** | بازیابی معنایی سبک TF-IDF+کسینوس با نرمال‌سازی فارسی (بدون وابستگی) + **سنجاق (Pin)** فکت‌های مهم + **فراموشی هوشمند** (Decay→آرشیو) + تگ‌گذاری |
| ⏮ **ماشین زمان** | snapshot کامل حافظه+مهارت هر پروژه؛ رول‌بک با خودِ نگه‌داشتن وضعیت فعلی؛ export/import پروژه به ZIP قابل‌حمل (به‌عنوان قالب هم می‌شود) |
| 🧩 **مهارت‌ساز حرفه‌ای** | نسخه‌بندی خودکار (هر تغییر بدنه = نسخهٔ جدید) + دیف یونی‌فایمد + ترکیب مهارت‌ها (`uses`) + Marketplace (فایل `.skill.md` قابل‌اشتراک) |
| 🤝 **زیرایجنت (Delegation)** | واگذاری زیرکار به نقش‌های `researcher/coder/reviewer` در همان گفت‌وگو + **بازتاب (Reflection)** پس از هر تسک که خودش را اصلاح می‌کند |
| ⛔ **انسان در حلقه** | ابزارهای خطرناک قبل از اجرا در UI کارتِ تایید با پیش‌نمایش آرگومان می‌گیرند (تایید/رد/TTL)؛ حالت risky هر پروژه مستقل است |
| 🛡 **ممیزی غیرقابل‌دستکاری** | لاگ append-only با زنجیرهٔ SHA-256 — دستکاری حتی یک فیلد با `/api/audit?verify=1` کشف می‌شود |
| 📊 **داشبورد مصرف** | شمارش تسک/دور/ابزار/توکن تخمینی به تفکیک روز و پروژه + روند ۱۴ روزه |
| 🚦 **محدودسازی نرخ** | سطل توکن + بازتلاش نمایی برای GitHub API (۴۰۳ نرخ/۴۲۹/۵xx/شبکه) — همهٔ متدهای گیت‌هاب خودکار محافظت می‌شوند |
| 🐍 **سندباکس کد** | اجرای Python/Shell در subprocess ایزوله (تایم‌اوت سخت، سقف خروجی، env سفیدلیست) + ابزارهای فایل با «زندان مسیر» و Trash |
| ⏰ **زمان‌بند + نگهبان** | jobهای `interval/daily` برای اجرای خودکار تسک در پروژه؛ نظرسنجی مخزن‌های گیت‌هاب (Issue/PR/push) با اعلان و واکنش خودکار |
| 🔔 **اعلان‌ها + چندسشن** | مرکز اعلان با بج خوانده‌نشده؛ چند سشن چت موازی روی یک پروژه با حافظهٔ مشترک و گفت‌وگوی ایزوله (مغز مشترک نوبتی) |
| 🔄 **چرخش خودکار چت (Rollover)** | اگر context چت به سقف نزدیک شود (تخمین ≥۸۵٪ سقف ~۱M توکن) یا خود سایت پیام سقف بدهد، **چت جدید در سایت ساخته می‌شود** و «راهنمای پروژه» (persona + حافظهٔ سنجاق/مرتبط + مهارت‌ها + خلاصهٔ پیشرفت و پیام معلق) تزریق می‌شود تا تسک **از همان نقطه بی‌وقفه ادامه یابد** — بدون دست دادن اطلاعات پروژه |
| 💾 **چک‌پوینت/Resume** | ذخیرهٔ وضعیت حلقه در پایان هر دور؛ ادامهٔ تسک نیمه‌کاره از همان‌جا بعد از قطعی |
| 🎭 **persona پروژه** | دستورالعمل همیشگی هر پروژه که به پرامپت سیستمی تزریق می‌شود |
| 🕹 **UX v4** | نوار سشن‌ها، زنگ اعلان، پنل داشبورد (زمان‌بند/نگهبان/ممیزی/مصرف/خط‌زمانی/چک‌پوینت)، **جستجوی سراسری با ⌘K**، استریم جزئی پاسخ، بج پروژه روی هر تسک |
| 🧰 **یادگیری مهارت** | بعد از هر تسک موفق، مدل یک «مهارت قابل‌استفادهٔ مجدد» استخراج می‌کند (پروتکل DISTILL) و در کتابخانه ذخیره می‌شود؛ با هر استفاده، آمار usage/success به‌روز و مهارت‌های مرتبط در تسک‌های بعدی تزریق می‌شوند — **در طول کار اسکیل یاد می‌گیرد** |
| 📚 **درس‌آموزی از خطا** | اگر ابزاری خطا داد، پایان تسک یک درس اکشن‌پذیر در حافظه ثبت می‌شود تا همان اشتباه تکرار نشود |
| 📡 **رویدادمحور (Event-driven)** | موتور ایجنت هر دور/ابزار/نتیجه/پروژه را به‌صورت رویداد منتشر می‌کند؛ هم CLI و هم وب از یک موتور مشترک استفاده می‌کنند |
| 🖥️ **رابط وب DevX** | داشبورد HUD زنده: استریم SSE، خط‌زمانی ابزارها، پنل حافظه، مرورگر مهارت‌ها، وضعیت گیت‌هاب، اثر ماشین‌نویس، رادار، LEDهای چشمک‌زن |
| 🧩 **پلاگین‌پذیری کامل** | رجیستری ابزار با JSON-Schema؛ افزودن ابزار جدید بدون دست زدن به موتور (سبک morx-gms2-mcp) |
| 🔁 **مغز-مستقل (Brain-agnostic)** | هر کلاینتی با `send/wait_response/new_chat` می‌تواند مغز باشد (دیپ‌سیک اکنون؛ FakeBrain برای تست؛ API رسمی در آینده) |
| 🛡️ **امنیت توکن** | توکن فقط با `getpass` یا مودال UI گرفته می‌شود، با `GET /user` اعتبارسنجی و **فقط در حافظهٔ همان اجرا** نگه داشته می‌شود |

```
                                                  │ ├ github_tools.py (۲۹)   │

                                                  └──────────────────────────┘
```

**پروتکل ابزار (چرخهٔ ایجنت):** مدل فقط `{"tool": "...", "arguments": {...}}` می‌فرستد → ابزار اجرا → نتیجه با پیشوند `TOOL_RESULT` برمی‌گردد → تا `{"final_answer": "..."}` یا سقف `MAX_ROUNDS` (پیش‌فرض ۱۰).

**چرخهٔ یادگیری:** پایان تسک موفق → `META/DISTILL` به همان گفت‌وگو → JSON مهارت → ذخیره در کتابخانه → تسک‌های بعدی مشابه، ابتدا مهارت مرتبط را در پرامپت می‌بینند.

## نصب و اجرا

پیش‌نیاز: Python 3.10+

```bash
pip install -r requirements.txt
playwright install chromium        # مرورگر کرومیوم
cp .env.example .env               # تنظیمات (اختیاری)
```

### رابط وب DevX (پیشنهادی)

```bash
python devx.py                     # → http://127.0.0.1:8770 (باز شدن خودکار)
python devx.py --port 9000         # پورت دلخواه
python devx.py --no-browser        # فقط سرور
```

۱. صفحهٔ DevX باز می‌شود؛ مودال توکن گیت‌هاب ظاهر می‌شود → توکن `ghp_` را بده (اعتبارسنجی با `GET /user`) یا «فعلاً نه» را بزن.
۲. اگر اکانت دیپ‌سیک لاگین نباشد، **نوار هشدار چشمک‌زن** بالای صفحه می‌آید → دکمهٔ «باز کردن پنجرهٔ ورود» → در پنجرهٔ کرومیوم دستی وارد شو (یک‌بار برای همیشه، پروفایل ماندگار است).
۳. LED وضعیت `DEEPSEEK` فیروزه‌ای و پالس‌دار می‌شود → تسک بده.

### چرخهٔ پروژه‌ها (وب)

- در شروع (و با دکمهٔ **«＋ چت جدید»**) مودال «نام پروژه» باز می‌شود: نام را بنویس (مثلاً «تست») → **آیدی خودکار در پس‌زمینه ثبت می‌شود** (#۱) و حافظهٔ ایزولهٔ همان پروژه فعال می‌شود.
- از همان مودال می‌توانی به پروژه‌های قبلی برگردی (کلیک = سوییچ با حافظهٔ خودش)، نام را دبل‌کلیک تغییر دهی یا با 🗑 حذف کنی — **آیدی‌ها بعد از حذف خودکار بازچینش می‌شوند**.
- چیپ زرد `PROJ #n` در هدر همیشه پروژهٔ فعال را نشان می‌دهد؛ کارت هر تسک هم بج پروژهٔ خودش را دارد.
- اگر بدون انتخاب پروژه تسک بدهی، خودکار «پروژه N» ساخته می‌شود تا هیچ کاری بی‌پروژه نماند.

## گرفتن GitHub Classic Token

۱. **https://github.com/settings/tokens** → `Generate new token (classic)`
۲. اسکوپ‌ها:

| اسکوپ | برای چه |
|---|---|
| `repo` | **حداقل لازم** — مخازن عمومی/پرایوت: کد، Issues، PR، Release |
| `workflow` | ساخت/ویرایش و اجرای Actions |
| `delete_repo` | فقط برای ابزار `delete_repo` (پیش‌فرض نیست) |

۳. ⚠️ توکن کلاسیک به‌طور پیش‌فرض به منابع **سازمان‌ها** هم دسترسی دارد (مگر سازمان محدودش کرده باشد) — با احتیاط بساز و پس از کار حذف کن.
۴. 🔒 توکن فقط در حافظهٔ همان اجرا می‌ماند (CLI: `getpass`، وب: مودال + POST به سرور محلی خودت)؛ هرگز در فایل/لاگ/کد ذخیره نمی‌شود.

```
└── tests/               ← ایستا + پروژه‌ها + هستهٔ DevX + دود سرور + فقط‌خواندنی واقعی
```

## تنظیمات کلیدی `.env`

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `DEEPSEEK_USER_DATA_DIR` | `./.deepseek_profile` | پروفایل ماندگار اکانت دیپ‌سیک |
| `MAX_ROUNDS` | `10` | سقف دورهای ابزار در هر تسک |
| `DEVX_PORT` | `8770` | پورت رابط وب |
| `MEMORY_DIR` | `./memory` | محل حافظهٔ ماندگار |

| `AUTO_LEARN_LESSON` | `true` | ثبت درس پس از خطای ابزار |
| `RESPONSE_TIMEOUT` | `240` | مهلت انتظار پاسخ دیپ‌سیک (ثانیه) |

## عیب‌یابی

- **نوار هشدار چشمک‌زن «لاگین دیپ‌سیک لازم است»** → دکمهٔ «باز کردن پنجرهٔ ورود» را بزن و در پنجرهٔ کرومیوم وارد شو؛ پروفایل ماندگار است و تکرار نمی‌شود. در `DEEPSEEK_HEADLESS=true` ورود دستی ممکن نیست.
- **«textarea#chat-input پیدا نشد»** → UI دیپ‌سیک عوض شده؛ سلکتورها ثابت کلاس در `deepseek_client.py` هستند.
- **پاسخ ناقص** → `RESPONSE_TIMEOUT` یا `RESPONSE_STABLE_CHECKS` را بالا ببر.
- **۴۰۳ گیت‌هاب** → ابزار `get_rate_limit` یا پنل GitHub در DevX (سهمیه‌سنج).
- **توکن گم شده بعد از ری‌استارت** → طبیعی است؛ توکن عمداً فقط حافظه است — دوباره در مودال بده.
- **حافظهٔ خراب** → فایل `memory/memory.json.corrupt.bak` بکاپ می‌شود و ایجنت از نو شروع می‌کند.
- **حافظهٔ پروژه‌ها کجاست؟** → `memory/projects/<key>/memory.json` و `skills_learned/projects/<key>/*.md`؛ فهرست/آیدی‌ها و پروژهٔ فعال در `memory/projects.json`. کلید پایدار (key) داخلی است و تغییر آیدی‌ها هرگز داده‌ها را جابه‌جا نمی‌کند.
